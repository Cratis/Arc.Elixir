# Event model explorer

The explorer that Cratis Arc for Elixir serves under `/.cratis/event-model`: a small Vite and React
application over [`@cratis/event-models`](https://www.npmjs.com/package/@cratis/event-models) (the
board) and `@cratis/screenplay-language` (the source view). It is the same explorer the C# Arc
embeds, and it talks to the same routes, so the two stay interchangeable.

It is **built into the package**, not committed: `npm run build` writes `Source/arc/priv/event_model`,
which is listed in the package files and ignored by git. The publish workflow runs the build before
`mix hex.publish`; the pull request build runs it so it cannot break unseen.

```bash
cd Source/event_model_viewer
npm ci
npm run build        # into ../arc/priv/event_model
npm run typecheck
npm run dev          # Vite on :5290, proxying /.cratis/event-model/* to an Arc app on :4000
```

What the application reads is generated by `Arc.EventModel` while your app compiles (see
`Mix.Tasks.Compile.ArcEventModel`), not by this project.
